## Evidence conventions

- `PASS` means the stated behavior was observed; it does not imply comprehensive feature coverage.
- `FAIL` means observed behavior differed from the expected result.
- `BLOCKED` means the feature requires a dependency deliberately not configured or used in this local run.
- `NOT TESTED` means no execution evidence was collected.
- `INCONCLUSIVE` means available evidence was insufficient to decide.
- `NOT APPLICABLE` means the feature does not exist or does not apply.
- Cross-browser full-page/viewport JPEG evidence and the machine-readable 73-route results are stored in [qa-evidence/cross-browser](./qa-evidence/cross-browser/); representative PNG evidence remains in [qa-evidence](./qa-evidence/).
- The 2026-10-24 UI follow-up screenshots, browser recordings, and structured results are in [qa-evidence/live-ui-2026-10-24](./qa-evidence/live-ui-2026-10-24/). The live app used an isolated MySQL QA database because this application runtime was configured for MySQL; no production service or account was used.
